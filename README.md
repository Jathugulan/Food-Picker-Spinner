# 🍕 Food Picker Spinner (FoodSpin)

A modern, responsive food decision-making web application that randomly selects what to eat. FoodSpin provides an interactive spinner wheel, food management, categories, favorites, history, analytics, themes, and local data storage.

## ✨ Features

* 🎡 Interactive food spinner wheel
* 🍱 Add, edit, delete, and search foods
* ❤️ Favorite foods
* 🏷️ Custom food categories
* 📊 Statistics and analytics
* 📜 Spin history
* 🌙 Light, dark, and system themes
* 💾 LocalStorage data persistence
* 📤 Backup and restore data
* 📱 Fully responsive design
* 🎨 Modern glassmorphism UI
* ⚡ Smooth animations

## 🛠️ Technologies

* React 19
* Vite
* Tailwind CSS
* Framer Motion
* Recharts
* React Router
* Lucide React
* HTML5 LocalStorage

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/food-picker-spinner.git
cd food-picker-spinner
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

Open:

```text
http://localhost:5173
```

## 📖 Usage

1. Open the **Spinner** page.
2. Select a food category or choose **All Foods**.
3. Click **Spin the Wheel**.
4. View the randomly selected food.
5. Add, edit, delete, search, or favorite foods from the **Foods** page.
6. Manage categories from **Categories**.
7. View your spin statistics and history.
8. Use **Settings** to manage themes and backup/restore data.

## 🌐 Deployment

### Vercel

1. Push the project to GitHub.
2. Open [Vercel](https://vercel.com/).
3. Sign in with GitHub.
4. Click **Add New → Project**.
5. Import the `food-picker-spinner` repository.
6. Select **Vite** as the framework.
7. Use:

   * Build Command: `npm run build`
   * Output Directory: `dist`
8. Click **Deploy**.

After deployment, Vercel provides your live website URL.

## 🔄 Update Deployment

After making changes:

```bash
git add .
git commit -m "Update Food Picker Spinner"
git push
```

Vercel automatically deploys the latest GitHub changes.
